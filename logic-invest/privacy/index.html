로직투자

개인정보 처리방침

시행일 2026년 11월 12일

1. 적용 범위

이 방침은 로직투자(@logic.invest.kr)가 공개 기업공시를 Instagram에 게시하고, SEARFin Page Publishing 앱을 통해 로직투자 Facebook 페이지에 공유하는 기능과 이 방침에 관한 문의에 적용됩니다.

2. 처리하는 정보와 목적

  • 앱은 관리자가 승인한 Meta 페이지 접근 권한으로 페이지 식별자와 이름, 게시물 식별자, 게시 상태와 링크를 처리합니다. 이 정보는 게시 대상을 확인하고, 같은 공시가 중복 게시되는 것을 방지하며, 게시 결과를 확인하는 데 사용합니다.
  • 자동 게시 기능은 독자의 Facebook 로그인이나 회원가입을 요구하지 않으며, 독자의 프로필, 친구 목록, 댓글 또는 메시지를 Meta API에서 조회하지 않습니다.
  • 개인정보 관련 문의를 이메일로 보내면 발신 이메일 주소와 사용자가 직접 제공한 내용을 문의 답변 및 권리 요청 처리에 사용합니다.

3. 보유와 삭제

페이지 접근 토큰은 연결을 운영하는 동안 권한이 제한된 운영 환경에 보관합니다. 연결이 해제되거나 토큰을 교체하면 사용이 끝난 토큰을 폐기합니다. 공시 접수번호, 게시물 식별자, 링크는 게시 결과 확인과 중복 방지에 필요한 동안 보관합니다. 문의에 포함된 개인정보는 처리 목적이 달성되면 삭제하며, 법령에 따른 보존 의무가 있으면 해당 기간 동안 보관합니다. 전자 파일을 파기할 때는 해당 파일과 저장된 사본을 복구할 수 없는 방법으로 삭제합니다.

4. 외부 서비스

로직투자는 Meta에 게시할 공개 공시 요약과 연결할 게시물 링크를 전송합니다. Facebook과 Instagram의 계정, 방문 및 이용 정보는 Meta의 개인정보처리방침에 따라 처리됩니다. 이 안내 페이지는 GitHub Pages에서 제공되며, 호스팅 과정에서 접속 IP 주소 등 기술 정보가 GitHub의 정책에 따라 처리될 수 있습니다.

5. 열람·정정·삭제 요청

로직투자가 처리하는 본인 정보의 열람, 정정, 삭제 또는 처리정지를 요청하려면 개인정보 문의 담당 이메일로 연락해 주세요. 요청을 처리하는 데 필요한 경우 본인 또는 대리인 여부를 확인합니다. 페이지 관리자는 Facebook에서 앱 권한을 철회할 수 있습니다.
